# Stock Monitor

<img src="web/public/stock-monitor-logo.png" alt="Stock Monitor logo" width="80" height="80" />

面向零金融基础用户的本地股票观察工具。首页先回答“相对历史偏贵还是偏便宜”，再用营收、净利率、PE 和股数推演未来情景股价。详细财务与长期投资研究保留在二级入口，不再同时铺满首页。

公开仓库不包含个人数据库、日志、凭证、依赖目录或研究材料。整个 `research/` 目录仅保留在本地，不参与 Git 跟踪与上传。首次启动会从公开财务源获取数据；新 logo 同时用于网页导航与浏览器标签页。

## 价格概览

- 首屏只突出估值结论、收盘 PE 和自身历史位置。低于或等于 20% 分位显示“偏便宜”，高于或等于 80% 显示“偏贵”，其余显示“中间价位”；这是相对历史，不是内在价值或买入建议。
- 非经营利润显著时显示“PE 需核查”；缺失、过期或断线时不作价格判断。谷歌仍明确使用三年窗口，不能冒充十年。
- 股价推演采用 `未来年化营收 × 未来净利率 × 未来 PE ÷ 未来股数`。首页可调一至两年的营收增长、净利率和 PE，基期营收、股数、稀释与原文依据默认折叠。
- 英伟达可一键带入《十万亿不是梦？》的文章基期与 70% / 30% 增长、20 倍 PE。改动参数后明确标为自定义，原始文章不改写。
- 未来情景股价未折现，不是今天的合理价。异常净利率不自动外推，新台币营收不会与美元股价直接混算。
- 点击“详细研究”可进入原有投资理由、财务指标、现金折现和个人备忘；原有数据与参数保留。

公式、数据来源与计算边界可在网页中展开查看；详细研究文档仅保留在本地。

## 投资研究

- **投资研究**：各公司独立的商业模式、竞争优势假设、支持理由、风险与可证伪条件；数值可展开查看期间、公式和数据来源。
- **指标明细与经营记录**：五年营收复合增长、营业利润率、现金兑现、自由现金率、再投资占比、五年正现金记录、平均权益 ROE、已识别长期债务/经营现金、盈利收益率。
- **价格纪律**：可编辑每股现金、增长、要求回报、长期增长与安全折价；展示十年现金折现、终值占比与九格敏感性。未复核参数明确显示为试算。
- **我的论点**：按公司保存持有理由、反证条件和候选标记。参数/财报变化后，旧的假设确认失效；普通报价轮询不重置参数。
- **公司对比**：按正自由现金、五年现金持续性与个人候选筛选，可按增长、利润率、ROE 等排序；不同历史窗口保持明示，不合成一个伪精确选股分数。
- **财报监控**：保留原来的行情、严格日频 PE、最新财务、现金投入与文章情景。

参数、个人论点和候选标记保存在本机浏览器 `localStorage`，不是服务器备份；清理浏览器存储会丢失这些个人记录。不会触发交易。

营收推演参数使用独立的本地存储键，不覆盖此前的现金折现参数、论点和候选标记。

## 启动网页

需要 Python 3.11 和 Node.js 22。在项目目录的 PowerShell 中运行：

```powershell
.\start.ps1
```

然后访问 `http://127.0.0.1:8765`。

首次启动会安装依赖、构建网页，并启动独立的 Windows 后台进程。关闭网页或启动终端不会停止监控。电脑关机、休眠或离线时无法采集；这不是外部托管的全天候服务。

```powershell
.\start.ps1 -Stop
.\start.ps1 -Foreground
.\start.ps1 -SkipBuild
```

依次对应：停止托管进程、前台调试启动、使用已有构建启动。默认地址 `http://127.0.0.1:8765`，端口被占用时可传 `-Port 8766`。已健康运行的实例不会重复启动；修改代码后先停止再启动。

- CNBC 报价约每 60 秒更新，源数据可能延迟。
- SEC Submissions 全天约每 5 分钟检查新财报，新申报触发 Company Facts 刷新；XBRL 滞后时自动重试。
- PE 估值通常每 6 小时更新，新申报或财务变更时失效重算；缺数据/失败状态约 5 分钟重试，每分钟检查缓存。
- 网页每 15 秒同步后台结果，不必手动刷新。
- SQLite 保留报价、申报、财务版本和 PE 样本，数据库位于 `data/stock-monitor.db`。
- 日志位于 `logs/`；可设置 `SEC_CONTACT` 为实际联系邮箱以遵循 SEC 自动访问身份规范。

## 当前能力

- 默认监控微软、英伟达、亚马逊/AWS、谷歌、苹果和台积电
- 输入公司名称、股票代码或 `AWS` 搜索和新增标的
- 苹果、微软、英伟达、亚马逊、台积电采用通过交易日覆盖检查的十年 PE；谷歌目前只有三年窗口合格，十年值留空
- PE 使用四个独立季度的已披露稀释 EPS，不再用年度与累计 EPS 加减拼接；年度采样已退出生产路径
- 展示盈利收益率、历史倍数对应价格、四季原始 EPS 和报告链接；历史参考价格不是合理价或目标价
- 前端所有预置公司都使用后台财务及估值，不再只更新报价
- 财务按单季/年度/累计期间对齐；年度利润不会作为季度利润再乘四
- 台积电财务来自最新官方季度业绩与管理报告，保留新台币；估值使用公司披露的美元 ADR EPS，不混币种
- 谷歌、亚马逊的大额非经营利润触发核查提示；自由现金仍为负时不会仅因环比改善标成健康
- 未来情景单独保留研究假设；英伟达作者情景不是当前盈利预测或买入保证
- 数据源失败保留带日期的旧值；过期、断线、新财报未追上或历史价格异常重标定时撤回判断

当前算法为版本 4。算法及原始证据可在网页与 API 中查看；本地研究报告、导出样本和归档材料不随公开仓库发布。

这是一套有来源和失效门槛的投资研究工具，不是经过独立财务审计的交易系统。公司行动规则、维持性资本开支、一次性项目、全部负债和业务判断仍需人工核对；新增公司尚未配置拆股规则时不会发布 PE 分位。

## 目录结构

```text
research/source-articles/
├── manifest.json                 # 五篇文章的总清单
└── <article-slug>/
    ├── article.txt               # 纯文本正文
    ├── article.md                # 按原文位置插入本地图片的 Markdown
    ├── article.html              # 可离线打开的本地化正文
    ├── metadata.json             # 标题、作者、发布时间、来源和统计
    ├── images.json               # 图片原地址、本地路径、大小和 SHA-256
    ├── source.html               # 微信原始页面响应
    └── images/                   # 原文顺序编号的图片文件
```

## 重新归档文章

```powershell
python -m pip install -r scripts/requirements.txt
python scripts/archive_wechat_articles.py
python scripts/verify_archive.py
```

只更新一篇时可重复传入 `--only <slug>`。增量运行会保留总清单中的其他文章。
